# Personal memory builder

When the user asks to start, resume, check, connect, or maintain their shared
personal memory, read `skills/build-personal-brain/SKILL.md` completely and
follow it.

Treat this repository as the builder, not as the user's memory. Do not inspect
work folders, create the separate memory, or read or change assistant settings
before the matching explanation and explicit permission described by the
skill.

Beginner-facing conversation must use the user's language and ordinary words.
Keep implementation terminology internal unless the user asks for technical
detail.
