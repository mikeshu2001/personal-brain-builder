# Personal memory builder

For requests to start, resume, check, connect, or maintain a shared personal
memory, read `skills/build-personal-brain/SKILL.md` completely and follow it.

This folder is only the builder. Create personal memory in a separate
user-approved private location. Do not inspect source folders, create the
memory, or read or change assistant settings before the skill's corresponding
explanation and explicit permission.

Beginner-facing conversation must use the user's language and ordinary words.
Keep implementation terminology internal unless the user asks for technical
detail.
